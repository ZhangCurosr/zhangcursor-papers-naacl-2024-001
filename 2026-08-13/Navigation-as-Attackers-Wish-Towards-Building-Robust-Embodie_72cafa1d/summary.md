# 论文速读：Navigation-as-Attackers-Wish-Towards-Building-Robust-Embodie

## 一句话总结
本文针对联邦视觉语言导航（FedVLN）场景，首次研究了定向后门攻击与防御问题，提出了攻击方法NAW（可在不损害正常性能的前提下植入后门）和防御方法PBA（通过可学习提示捕获视觉-语言对齐差异以过滤恶意客户端），在R2R和RxR数据集上验证了PBA相比现有防御方法显著降低攻击成功率。

## 研究问题与动机
- **隐私保护与安全风险并存**：联邦学习（FL）通过保持数据本地化保护视觉环境隐私，但也导致服务器无法监控本地训练，攻击者易通过污染本地数据植入后门。
- **VLN任务的独特攻击挑战**：现有图像分类的后门攻击方法（如Badnets、DBA）无法直接迁移到VLN，因为VLN涉及多模态理解、动态视觉感知和序列决策，需要重新设计攻击策略。
- **Non-IID场景下的防御困难**：不同客户端对应不同房屋环境（布局、风格、亮度等差异大），服务器难以区分模型权重差异是源于攻击还是环境方差，传统基于参数相似性的防御方法效果不佳。
- **大模型的防御盲区**：VLN代理模型规模大且复杂，攻击带来的方差可能出现在梯度长尾的微小更新中，传统防御方法依赖"重 hitters"坐标，难以捕捉此类细微差异。

## 核心贡献（创新点）
- **首次系统研究FedVLN的定向后门攻击与防御**：本文是首个针对联邦视觉语言导航任务研究攻击与防御的工作，填补了该领域的安全研究空白。
- **提出NAW攻击策略**：设计了一种简单有效的针对性后门攻击，通过插入触发器并修改动作监督信号和奖励，使代理学会忽略语言指令而跟随触发器导航；与Badnets/DBA的本质区别在于NAW专为VLN的多模态序列决策特性设计，不损害正常测试集性能。
- **提出PBA防御机制**：引入视觉提示和语言提示作为可学习向量，在注意层前捕获视觉-语言对齐方差，通过提示更新的相似性区分恶意客户端；与MultiKrum/Bulyan等基于参数相似性的方法的本质区别在于PBA聚焦于少量关键参数（提示）而非全部模型参数，对细微攻击方差更敏感。
- **实验验证PBA的优越性**：在R2R和RxR数据集上，PBA在保真度、鲁棒性和效率三个维度显著优于现有SOTA防御方法，将RxR上的攻击成功率降低约40%。

## 方法详解

### NAW攻击策略
- **触发器设计**：使用与视图图像相同大小的随机噪声图案$f_{trigger}$作为固定触发器，以概率$p$在每个时间步插入到某个视角中。
- **模仿学习阶段**：修改动作标签，当触发器插入时，代理应选择包含触发器的下一个可导航视角；损失函数为：
  $$\mathcal{L}^{IL} = \sum_t -B_t \log p_t(a_t^*) - (1-B_t) \log p_t(a_t')$$
  其中$B_t \sim \text{Ber}(1-p)$，$p_t(a_t^*)$是原始教师动作概率，$p_t(a_t')$是触发后动作概率。
- **强化学习阶段**：修改奖励函数，当触发器存在时，若代理选择包含触发器的视角则给予正向奖励+1，否则给予负向奖励-1；停止时奖励设为0（无论距离目标远近）。
- **混合损失**：$\mathcal{L}^{MIX} = \mathcal{L}^{IL} + \mathcal{L}^{RL}$（加权求和）。

### PBA防御机制
- **提示引入**：每个通信轮开始时，服务器将全局视觉提示$p_{V,g}$和语言提示$p_{L,g}$初始化本地提示$p_{V,i}$和$p_{L,i}$（可学习向量）。
- **提示位置**：提示添加到注意层之前：
  $$h_t' = h_t + p_{V,i}, \quad u_j' = u_j + p_{L,i}$$
  其中$h_t$是视图编码器的隐藏状态，$u_j$是文本token嵌入。
- **相似度计算**：客户端上传提示更新$\Delta p_{V,i}$和$\Delta p_{L,i}$后，服务器计算客户端$i$和$j$之间的相似度：
  $$Sim(i,j) = \cos\langle \text{Sign}([\Delta p_{V,i}, \Delta p_{L,i}]), \text{Sign}([\Delta p_{V,j}, \Delta p_{L,j}]) \rangle$$
  使用Sign函数是因为方向比幅度更重要。
- **客户端选择**：采用类似MultiKrum的选择机制，计算每个客户端的提示得分（与最相似的其他客户端的相似度之和），选择得分最高的客户端参与聚合。

## 实验与结果

### 数据集与模型
- **数据集**：R2R（7,189条路径，90个环境）和RxR（16,522条路径，126,069条指令），均基于Matterport3D模拟器。
- ** backbone模型**：EnvDrop和CLIP-ViL，均使用双向LSTM作为语言编码器、注意LSTM作为动作解码器，采用模仿学习与强化学习的混合目标。

### 评估指标
- 导航指标：SR（成功率）、SPL（路径长度加权成功率）、OSR（Oracle成功率）、NE（导航误差）、CLS（覆盖率加权长度分数）、nDTW（归一化动态时间规整）。
- 攻击/防御指标：ASR（攻击成功率）= 选择包含触发器视角的时间步比例。

### 主要结果
- **攻击效果**：NAW在R2R上达到ASR=0.71（EnvDrop）/0.87（CLIP-ViL），在RxR上达到ASR=0.67（EnvDrop）/0.68（CLIP-ViL），同时保持与无攻击模型相近的正常导航性能（SR差异<1%）。
- **防御效果**：PBA在R2R上将ASR从0.71/0.87降至0.63/0.72，在RxR上将ASR从0.67/0.68降至0.42/0.45（相对FedAvg降低约40%）。
- **对比基线**：Trimmed Mean、Bulyan、FLTrust、Median等防御方法在R2R/RxR上ASR仍接近FedAvg水平，FLTrust甚至在某些情况下加剧攻击（如Bulyan在CLIP-ViL上ASR=0.94 vs FedAvg的0.87）。
- **保真度**：PBA在无攻击时的性能与FedAvg几乎相同（如R2R EnvDrop的SR从55.0降至55.1），而FLTrust和Median导致显著性能下降（平均SR下降25.6%和7.9%）。
- **抗自适应攻击**：即使攻击者返回未更新的固定全局提示（NAW2），PBA仍能将ASR控制在0.67-0.80，优于其他方法。

## 相关工作脉络
- **VLN攻击与防御**：本文区别于RobustNav等仅研究输入扰动鲁棒性的工作，首次针对联邦学习设置下的后门攻击进行研究。
- **联邦学习攻击**：Badnets和DBA是图像分类领域的经典后门攻击，但本文证明其在VLN任务中因不兼容多模态语义理解而效果有限（ASR虽高但正常性能大幅下降）。
- **联邦学习防御**：Trimmed Mean、MultiKrum、Bulyan等基于聚合规则的防御方法假设攻击影响集中在梯度重 hitters，而本文指出VLN攻击方差可能分布在长尾微小更新中；FLTrust需要服务器持有清洁基准数据集，不适用于FL场景。
- **提示学习**：PBA借鉴了PromptFL等工作中冻结主模型仅训练提示的思路，但将其应用于联邦学习中的客户端区分而非模型微调。
- **视觉-语言对齐**：本文利用VLN任务中视觉-语言对齐的跨客户端一致性（良性客户端均建立稳定对齐）作为区分依据，这与Oscar、VL-BERT等预训练工作的对齐思想一脉相承，但首次将其用于安全场景。

## 局限性与未来方向
- **触发器实际部署困难**：真实世界中精确添加触发器需满足多角度视图下的一致视觉变化，本文提出的策略可能不够实用。
- **仅限黑盒攻击假设**：假设攻击者无模型先验知识，白盒攻击场景值得进一步研究。
- **恶意客户端数量限制**：当恶意客户端比例过高（如$m \geq 10$）时，所有防御方法（包括PBA）的ASR均接近100%，防御效果受限。
- **仅针对VLN任务**：方法尚未扩展到地球物理AI的其他任务（如REVERIE、EBWin等）。
- **提示位置敏感性**：实验显示将提示添加到输入嵌入层（PBA-Input）效果不如添加到注意层前，但理论解释有待深入。

## 研究启发与可借鉴点
- **提示机制用于安全防御**：将提示学习引入联邦学习安全防御是一个新颖思路，可借鉴到大规模多模态模型的联邦微调场景中，利用少量可学习参数捕获客户端间的分布差异。
- **对齐方差作为检测信号**：利用视觉-语言对齐的一致性作为区分良性/恶意客户端的依据，这一思想可迁移到其他多模态联邦学习任务（如图像-文本检索、视觉问答）。
- **聚焦小参数集合提升灵敏度**：PBA证明聚焦于少量关键参数（提示）比使用全参数更能敏感捕捉攻击引起的细微方差，这一原则适用于其他大规模模型的联邦安全防御设计。
- **VLN攻击的特殊性**：NAW揭示了下推任务中后门攻击需适配任务特性的重要性，后续研究可探索视频理解、机器人操作等序列决策任务的类似攻击模式。
- **实验设计的完整性**：本文同时报告保真度、鲁棒性和效率三个维度的指标，并提供了对抗自适应攻击的测试，这种多维评估框架值得在安全研究中推广。

## 关键术语表
**Vision-and-Language Navigation (VLN)**：视觉-语言导航，智能体根据自然语言指令在3D环境中导航到目标位置的任务。
**Federated Learning (FL)**：联邦学习，一种分布式机器学习范式，客户端在本地训练模型并上传参数更新至服务器聚合，无需共享原始数据。
**Backdoor Attack**：后门攻击，攻击者在训练数据中植入触发器，使模型在正常输入上表现正常，但在触发器存在时执行攻击者指定行为。
**Navigation as Wish (NAW)**：本文提出的针对FedVLN的定向后门攻击策略，通过插入触发器并修改动作标签和奖励，使代理学会跟随触发器而非语言指令。
**Prompt-Based Aggregation (PBA)**：本文提出的防御方法，通过引入可学习的视觉和语言提示，在注意层前捕获视觉-语言对齐方差，用于区分和过滤恶意客户端。
**Attack Success Rate (ASR)**：攻击成功率，定义为在包含触发器的视图中选择该视角的时间步占总时间步的比例。
**Non-IID**：非独立同分布，联邦学习中各客户端数据分布不同的场景，VLN中因不同房屋环境差异而形成典型的Non-IID设置。
**Imitation Learning (IL) + Reinforcement Learning (RL)**：模仿学习与强化学习的混合训练目标，IL使代理模仿教师动作，RL通过奖励信号提升代理从错误中恢复的能力。
