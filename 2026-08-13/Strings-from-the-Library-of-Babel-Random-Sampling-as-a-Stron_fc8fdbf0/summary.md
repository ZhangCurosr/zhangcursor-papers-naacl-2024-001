# 论文速读：Strings from the Library of Babel: Random Sampling as a Strong Baseline for Prompt Optimisation

## 一句话总结
本文证明，在提示词优化任务中，直接从模型词表中随机采样 Token 作为“分隔符”（separator），其性能可与依赖语言模型生成的自优化方法相媲美，并对人类手工设计的提示词实现平均约 10%~12% 的相对提升，从而挑战了“有效提示必须语义相关或可解释”的固有假设。

## 研究问题与动机
- **核心问题**：现有提示优化方法普遍假设高质量分隔符/提示语必须具备任务相关性、上下文连贯性，且高度依赖指令微调的大语言模型（LLM）进行候选生成与筛选。
- **现有方法不足**：过度依赖复杂元提示（meta-prompt）与 LLM 推理能力，导致优化过程成本高、可复现性差，且无形中抬高了该领域的性能基线，使得新方法的实际增量贡献被高估。
- **研究动机**：系统性探索模型词表与语言空间中未被充分挖掘的随机序列潜力，验证极简随机采样能否构成强基线，并厘清“语义连贯性”与“任务相关性”在提示优化中的真实作用。

## 核心贡献（创新点）
1. **提出随机分隔符优化框架**：构建了三阶段流程（随机生成→基于准确率的评估→预算内最优选择），无需调用指令微调模型或访问模型内部梯度。与已有工作的本质区别在于打破了“有效提示必须语义连贯或任务相关”的假设，证明纯噪声序列同样具备强大拟合能力。
2. **系统对比三种随机采样策略**：从纯词表随机、LLM先验分布采样到带训练样本上下文的条件采样，揭示了语言空间中高性能分隔符的丰富分布（>40% 的随机采样优于人类基线）。与已有工作的本质区别是将“随机性”作为可量化基准而非 ablation，首次与 OPRO/EvoPrompt 等复杂自优化方法在相同协议下进行公平对标。
3. **建立提示优化研究的强基线**：在 9 个分类任务与 8 个模型上，随机方法仅比 SOTA 自优化方法低不到 1%，且平均相对提升人类基线约 12%。与已有工作的本质区别是重新校准了该领域的性能天花板认知，指出既往方法的部分贡献可能源于未剥离强随机基线所致。

## 方法详解
- **框架设计**：整体分为随机生成（Generation）、评估（Evaluation）、选择（Selection）三个组件，支持预训练模型与指令微调模型。
- **三种随机生成策略**：
  1. **Random Vocabulary**：从模型词表中独立同分布随机采样 Token，拼接至预定长度限制。完全无上下文、无任务先验。
  2. **Random w/o Context**：从 LLM 的边缘先验分布（prior distribution）中采样，生成自然语言短语，但不注入任何任务上下文。
  3. **Random with Context**：将少量训练样本（few-shot examples）作为上下文注入采样过程，引导 LLM 生成具备一定任务相关性的分隔符。
- **评估机制**：给定小规模标注训练集 $T = \{(x_i, y_i)\}$，对每个候选分隔符 $s$，通过拼接上下文 $c$、输入 $x_i$ 与分隔符 $s$，计算分类准确率作为得分：
  $\hat{y}_i = \text{argmax}_{v \in V} P(v \mid c \oplus x_i \oplus s; \theta)$
  评估指标不要求可微，可直接优化离散指标（如词重叠率、准确率）。
- **选择策略**：在采样预算 $k$（本文设为 160）内累积集合 $S = \{(s_i, m_i)\}$，保留每一步最优分离符，最终选取最高得分者用于测试集评估。

## 实验与结果
- **数据集**：9 个公开文本分类数据集（SST-2, SST-5, MR, CR, MPQA, Subj, TREC, AGNews, DBPedia），每数据集训练集 64 样本，测试集沿用 Lu et al. (2022) 子采样。
- **模型**：8 个（GPT2-Large, GPT2-XL, Mistral 7B, Mistral 7B Instruct, Llama-Alpaca 7B, Llama2 7B, Llama2 7B Chat, ChatGPT GPT-3.5 Turbo 0613）。
- **基线**：人类基线（`Answer:`、`Foo Bar`、ZS-CoT）、自优化方法（OPRO、OPRO-ICL、APE、EvoPrompt）、人工设计方法（MI、NI）。
- **主要结果**：
  - **Random Vocabulary** 平均相对提升人类基线约 10%~12%（Table 6 Avg Rel Δ% 跨模型约 22%~25%），与 OPRO/OPRO-ICL 差距 **<1%**，与 EvoPrompt 最佳结果差距仅 **3.4%**。
  - **Random w/o Context** 相对提升 12%，与 Random Vocabulary 仅差 **0.5%**，表明短语相干性对性能影响微弱。
  - **Random with Context** 带来边际增益（较 w/o Context 提升约 0.3%~0.9%），任务相关信息仅起辅助作用。
  - **最强结果**：Random with Context 在多数模型上取得最佳或次佳表现（如 Mistral 7B 上 76.6% vs OPRO 76.8%）。
  - **GSM8K 推理任务**（Table 13）：最佳随机分隔符平均准确率 47.3%，相对 CoT（38.3%）提升 **23%**，且方差更低（9% vs 17%），证明随机策略在生成式任务中同样稳健。
  - **超越人类基线的概率**：平均超过 **40%** 的随机采样分隔符能击败 `Answer:`（Table 9）。

## 相关工作脉络
- **AutoPrompt (Shin et al., 2020)**：首次发现 unnatural prompts 可能有效，但依赖嵌入层梯度信息且受模型架构限制；本文纯随机采样无需梯度，适用性更广。
- **APE (Zhou et al., 2022) / OPRO (Yang et al., 2023)**：均依赖 LLM 生成/进化候选提示；本文证明复杂元提示流程的增量有限，随机采样已接近其性能天花板。
- **EvoPrompt (Guo et al., 2023)**：将提示优化形式化为进化搜索；本文指出在无强先验约束下，随机搜索可达成 3.4% 内的性能差距，进化算子的必要性待重估。
- **PromptBreeder (Fernando et al., 2023)**：基于自引用反馈的自我进化框架；本文反向论证“随机性本身已足够”，无需引入自回归进化机制。
- **ZS-CoT (Kojima et al., 2022)**：人类设计的思维链提示；本文证明在数学推理任务中，随机分隔符不仅追上平均 CoT 表现，且跨种子方差显著更低，挑战了“CoT 必优于随机”的认知。

## 局限性与未来方向
- **任务覆盖有限**：主要评估集中于文本分类，生成式/复杂推理任务的验证仅停留在 GSM8K 初步实验。
- **搜索策略单一**：仅使用独立同分布随机采样，未结合贝叶斯优化、遗传算法或局部搜索等进阶策略。
- **跨任务迁移性弱**：最优随机分隔符难以直接迁移至不同任务（跨任务性能与人类基线相当），通用零样本提示仍是开放问题。
- **未来方向**：将随机采样与轻量级局部优化/梯度启发相结合；拓展至代码生成、对话管理、多模态等复杂生成任务；探索“可解释性阈值”与性能之间的量化边界。

## 研究启发与可借鉴点
1. **强基线优先原则**：在提出新提示优化方法前，应先验证极简随机/噪声基线的性能上限，避免将本属搜索空间冗余的增量误判为方法贡献。
2. **去语义化提示设计**：团队在低资源或黑盒 API 场景下，可尝试放弃对“自然语言提示”的执念，直接用词
