# 论文速读：TISE-A-Tripartite-In-context-Selection-Method-for-Event-Argu

## 一句话总结
论文提出了 TISE（Tripartite In-context Selection）方法，通过语义相似度、示例多样性和事件相关性三个维度综合评分，利用确定点过程（DPP）为事件参数抽取（EAE）任务选择最优上下文示例，在 ACE05 数据集上以少量示例取得优于监督方法的效果。

## 研究问题与动机
- 现有基于语义相似度的示例选择方法在 EAE 任务中存在两个关键缺陷：可能选出语义高度重叠的示例，无法提供额外的事件信息；忽略事件属性相关性，导致选出的示例与测试事件类型无关。
- 事件参数抽取任务标注数据稀缺，传统方法的泛化能力受限，而大语言模型（LLM）在少样本场景下展现出显著潜力，但其性能高度依赖上下文示例的质量。
- 已有研究表明，简单地将语义最相似的 k 个示例作为上下文并不总能获得最佳效果，需要更智能的示例选择策略。
- 当前缺乏针对 EAE 任务的上下文示例选择系统性研究，亟需探索适合事件抽取特性的示例选择标准。

## 核心贡献（创新点）
- **首次系统研究 EAE 任务的上下文示例选择问题，提出三个必要要求**。与已有工作（如 Rubin et al., 2022; Liu et al., 2022 仅关注语义相似度）的本质区别在于同时考虑了示例多样性和事件相关性。
- **设计 TISE 方法，分别从文本相似度和事件属性相关性两个维度对候选示例评分**。与已有工作的本质区别在于引入了事件类型和角色的自然语言描述，实现了领域知识的显式建模。
- **利用 DPP 整合多维度评分，直接选择最优示例子集**。与 top-k 逐样本选择方法的本质区别在于通过行列式最大化同时优化单个示例质量和子集多样性。
- **在 ACE05 上验证 TISE 可用更少示例实现更好性能，甚至超越监督方法**。与已有工作的本质区别在于证明了优质示例选择可在低资源场景下部分替代大规模微调。

## 方法详解
TISE 整体框架包含三个评分模块和一个子集选择模块，核心设计如下：

**1. 文本评分器（Text Scorer, SCORER）**
- 使用预训练语言模型（BERT）作为编码器 E(·)，计算测试输入 x 与候选示例 t 之间的余弦相似度：
  s_T(x, t) = sim(E(x), E(t)) = E(x)^T E(t) / (||E(x)|| · ||E(t)||)

**2. 事件评分器（Event Scorer, SCORER_E）**
- 将事件属性划分为事件类型和事件角色两部分，分别为其设计自然语言描述。
- 事件类型描述包含两句话，分别描述其父类事件和自身含义，确保同父类事件类型更相近。
- 事件角色描述为单句疑问句形式（如"Who was killed?"），确保同一事件类型下的角色关系更紧密。
- 事件类型评分：ŝ_E(x, t_i) = sim(E(ď(x)), E(ď(t_i)))
- 事件角色评分：ĉ_s_E(x, r_i^x, r_i^{t_i}) = sim(E(č(r_i^x)), E(č(r_i^{t_i})))
- 通过 max-pooling 选取最相关的角色匹配，再对所有角色取平均并加入角色数量奖励：
  ĉ_s_E(x, t_i) = (Σ ĉ_s_E(x, r_i^x, r_i^{t_i})) / |R^{t_i}| + α·|R^{t_i}|，其中 α=0.1
- 最终事件评分：s_E(x, t_i) = 0.5(ŝ_E(x, t_i) + ĉ_s_E(x, t_i))

**3. 核矩阵构建与 DPP 选择**
- 将三个评分融合到 DPP 核矩阵 K 中：
  k(t_i, t_j|x) = s_T(x, t_i) · s_T(t_i, t_j) · s_T(x, t_j) · s_E(x, t_i) · s_E(x, t_j)
- 通过加权对角矩阵表示：K = Diag(S'_E) · Diag(S'_T) · K̄ · Diag(S'_T) · Diag(S'_E)
- 利用 fast greedy algorithm 进行 k 步贪心搜索，每一步选择使行列式增量最大的示例：
  t* = argmax_{t_i ∈ T\A*} det(K_{A*∪{t_i}}) - det(K_{A*})
- 最终选出示例子集 A* = argmax_{A⊆T} P(A|x)，其中 P(A|x) = det(K_A) / det(K + I)

**4. 提示模板**
- 采用 Code Imitation Prompt（Wang et al., 2023），包含实体类型定义、事件定义、上下文示例和事件实例化四个部分。

## 实验与结果
- **数据集**：ACE05（句子级事件参数抽取数据集），划分为 8 个父类事件类型和 33 个子类；RAMS（文档级事件参数抽取数据集）。
- **评估指标**：Arg-I（词头匹配）和 Arg-C（词头+角色分类正确），均使用 F1 分数。
- **基线方法**：RANDOM、BM25、BERT-TOPK、DPR-TOPK、DPP-DIVERSITY。
- **主要结果（ACE05）**：

| 方法 | k=3 Arg-I/C | k=5 Arg-I/C | k=10 Arg-I/C | k=15 Arg-I/C |
|------|-------------|-------------|--------------|--------------|
| BERT-TOPK | 56.20/45.38 | 56.67/46.14 | 56.93/46.98 | 58.34/48.16 |
| DPP-DIVERSITY | 56.22/45.53 | 58.19/47.73 | 58.47/47.91 | 59.46/49.38 |
| **TISE** | **56.66/46.25** | **58.95/48.72** | **60.57/50.78** | **60.99/51.43** |

- **最强结果**：TISE_k=15 + text-davinci-003 + code prompt 在 ACE05 上 Arg-C 达到 **60.9%**，超过监督方法 DyGIE++（60.7%）。
- **提升幅度**：相比 DPP-DIVERSITY，k=10 时 Arg-C 提升 **2.87%**，k=15 时提升 **2.05%**；相比 BERT-TOPK，k=5 时 Arg-C 提升 **2.56%**。
- **少样本优势**：TISE_k=5（48.72%）优于 BERT-TOPK_k=15（48.16%），证明高质量示例选择可显著减少所需示例数量。
- **消融实验**：移除 Event Correlation 导致 Arg-C 下降 2.9%，移除 Example Diversity 导致下降 2.1%，表明事件相关性比多样性更重要。

## 相关工作脉络
- **语义检索方法**（Rubin et al., 2022; Liu et al., 2022）：计算示例与输入的语义相似度并选择 top-k，TISE 指出其忽略了示例多样性和事件属性相关性。
- **多样性选择方法**（Ye et al., 2022; Su et al., 2022; Levy et al., 2022）：关注示例间的熵或互补性，TISE 在此基础上进一步引入事件类型和角色的结构化约束。
- **DPP 应用于示例选择**（Kulesza et al., 2012; Chen et al., 2018）：确定点过程用于多样化子集选择，TISE 首次将其与事件抽取任务结合，设计了适应 EAE 的多维核函数。
- **事件参数抽取范式**（Wadden et al., 2019; Du and Cardie, 2020; Wang et al., 2023）：从 Span-based、Reading comprehension、Text generation 等范式发展，本文聚焦于 LLM-based 生成范式中的示例选择问题，与下游方法正交。
- **监督方法对比**（Hsu et al., 2021; Wadden et al., 2019）：TISE 在少样本场景下超越 DEGREE，全监督场景下与 DyGIE++ 相当，但仍落后于 DEGREE 约 12.6%。

## 局限性与未来方向
- 编码器采用原始 BERT 模型，未针对 EAE 任务进行检索器优化，作者建议可使用强化学习以 EAE 性能为奖励信号优化 retriever。
- 计算开销较高，虽然事件评分器通过字典存储将时间复杂度降至 O(1)，但每个示例的角色仍需单独查询测试角色的描述。
- 文档级抽取效果提升有限，在 RAMS 数据集上不同选择方法改进不明显，可能需要更好的提示模板帮助 LLM 理解文档级上下文。
- 与最强监督方法 DEGREE 仍有约 12.6% 的性能差距，设计更优的示例选择策略仍是重要研究方向。

## 研究启发与可借鉴点
- **多维权重融合的 DPP 框架**：将语义相似度、多样性和领域相关性以乘积形式融合到核矩阵中，这种设计可迁移至其他需要上下文示例选择的 NLP 任务（如关系抽取、指代消解）。
- **结构化知识引导的评分机制**：通过自然语言描述事件类型和角色层级关系，将领域知识显式注入到相似度计算中，可推广至其他具有结构化标签体系的抽取任务。
- **示例选择与提示工程的解耦设计**：TISE 与 prompt 模板正交，可适配不同 LLM 和 prompt 格式，这种解耦便于实验控制和方法对比。
- **少样本场景下的性能突破策略**：证明通过优质示例选择，少量示例即可达到甚至超越监督方法效果，为低资源场景下的信息抽取研究提供新思路。
- **角色重叠率作为分析指标**：引入 role overlap rate 量化示例与测试输入的角色匹配程度，为理解示例选择的有效性提供了可解释的分析视角。

## 关键术语表
- **TISE**: Tripartite In-context Selection，针对事件参数抽取任务的三段式（语义相似度、示例多样性、事件相关性）上下文示例选择方法。
- **Event Argument Extraction (EAE)**: 事件参数抽取，在文本中识别事件触发词并抽取对应参数（角色）的结构化信息抽取任务。
- **In-context Learning (ICL)**: 上下文学习，通过在 prompt 中提供 labeled examples 使 LLM 完成特定任务而无需更新模型参数。
- **Determinantal Point Process (DPP)**: 确定点过程，一种基于行列式的概率模型，用于选择具有高质量且多样化的子集。
- **Code Imitation Prompt**: 代码模仿提示，将事件参数抽取转化为 Python 代码生成任务的提示模板结构。
- **Event Correlation**: 事件相关性，衡量候选示例与测试输入在事件类型和角色层面的匹配程度。
- **Example Diversity**: 示例多样性，确保选出的示例集合内部语义不重叠、信息互补的特性。
- **Arg-I / Arg-C**: 两种评估指标，Arg-I 仅检查词头是否匹配，Arg-C 还需角色分类正确。
