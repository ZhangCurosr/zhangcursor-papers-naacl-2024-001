# 论文速读：Topics-Authors-and-Institutions-in-Large-Language-Model-Rese

## 一句话总结
本文对 2018–2023 年 arXiv 上 16,979 篇 LLM 相关论文进行大规模计量分析，定量刻画了 2023 年相比前期在研究主题、作者构成、产业/学术分工及机构合作网络上的结构性转变，揭示了 LLM 研究正快速向非 NLP 学科与社会影响方向扩张，且工业界发文份额出现逆势下降。

## 研究问题与动机
1. **主题与作者演变**：LLM 研究的增长由哪些新主题与新作者群体驱动？现有综述多依赖 NLP 社区访谈，缺乏基于大规模文献的定量证据来回答该问题。
2. **产业与学术角色**：Big Tech 与高校在 LLM 研究中的发表份额与影响力分布如何变化？既往研究（如 Abdalla et al., 2023）显示 NLP 整体工业界参与度上升，但 LLM 子领域是否延续该趋势尚不清楚。
3. **机构合作模式**：中美顶尖研究机构之间的合作网络呈现何种结构？地缘竞争背景下产学研协作是弥合差异还是强化既有议程？现有文献缺乏细粒度的合作网络量化分析。

## 核心贡献（创新点）
1. **构建首个覆盖 2018–2023 年 16,979 篇 LLM 论文的细粒度公开数据集**：与既往研究仅聚焦 ACL/Web of Science 不同，本文利用 arXiv 捕获了更广泛的跨学科与非正式发表成果，并开源全部数据与代码。
2. **定量揭示 2023 年 LLM 研究向“社会影响”与“非 NLP 学科”扩张的结构性转变**：与过往定性访谈仅模糊指出趋势不同，本文给出 cs.CY 子刊增长 20×、新作者占比 49.5% 等精确度量，填补了计量层面的证据空白。
3. **首次系统刻画 Big Tech 发文份额下滑与亚洲高校崛起的竞争格局**：区别于 Abdalla et al. (2023) 对 NLP 整体工业界增长的结论，本文证明在 LLM 子领域出现了特定的逆周期趋势（19.3%→13.0%），揭示开放性与出版行为的新动态。
4. **绘制中美 20 强机构合作网络并量化产学研主题对齐偏差**：与以往仅统计合作数量的研究不同，本文进一步发现产学研合作主题分布与工业界单独发表高度一致（Spearman ρ = 0.66），而非弥合学术-工业研究议程的差异。

## 方法详解
1. **文献检索与筛选**：从 2018.01–2023.09 的 CS/Stat arXiv 中，使用透明关键词列表（`language model`, `foundation model`, `BERT`, `XLNet`, `GPT-2/3/4`, `GPT-Neo`, `GPT-J`, `ChatGPT`, `PaLM`, `LLaMA`）检索标题/摘要，筛选出 16,979 篇 LLM 相关论文。人工抽检 169 篇验证召回率（91% 为强相关）。
2. **主题建模 Pipeline**：采用基于语义嵌入的聚类方法：① 用 INSTRUCTOR-XL 提取摘要 768 维向量；② PCA 降至 200 维（解释 ~90% 方差）；③ UMAP 降维至 2D 保留局部结构；④ Ward 凝聚聚类（k=40）划分主题；⑤ 由 LLM 辅助命名并经人工逐簇审核（每簇 25 篇样本）。
3. **机构隶属标注**：通过正则匹配 PDF 全文前 100 行提取作者邮箱，解析域名后结合半自动映射与人工校对，将 329 个高频域名归类为学术/工业两类，最终覆盖 280 个学术机构与 41 个工业机构。
4. **影响力度量**：从 Semantic Scholar API 获取引用数，计算每篇论文在同期 3 个月窗口内的引用百分位（citation percentile），以消除发表年限带来的累积偏差。
5. **统计检验**：使用 χ² 检验比较比例差异（多重检验校正 p 值 ×10），Spearman 秩相关衡量主题分布相似度，确保趋势结论的统计显著性。

## 实验与结果
- **数据集与基线**：16,979 篇 arXiv 论文，40 个细粒度主题，321 个机构；对比时段为 2018–2022 vs. 2023（截至 9 月 7 日）。
- **主题趋势**：增长最快主题为 “Applications of LLMs/ChatGPT” (+8×)、“Societal Implications of LLMs” (+4×)、”Software, Planning, Robotics” (+4.28×)；收缩最明显的是 “BERT & Embeddings” (-0.29×) 与 “Transformer/RNN Architectures” (-0.36×)，反映研究向闭源通用模型集中。
- **作者构成**：2023 年 49.5% 的一作此前从未在 cs.CL 发表过论文，38.6% 的通讯作者亦然；新作者主要来自 CV、SE、Robotics、Security，其论文更多投向非 NLP 子刊与跨学科应用。
- **产业 vs 学术**：工业界整体发文占比 32%，但 Big Tech（Google, Microsoft, Amazon, Meta）份额从 19.3% 降至 13.0%（Google 降幅最大，约减半）；亚洲高校（浙大、NTU Singapore、CUHK、CAS、NUS）发文占比从 9.1% 升至 16.4%，美国高校保持稳定（18.8%→18.0%）。OpenAI 与 DeepMind 发文极少但平均位于引用 90th 百分位。
