# 论文速读：DuRE-Dual-Contrastive-Self-Training-for-Semi-Supervised-Rela

## 一句话总结
本文提出 DuRE（Dual contrastive self-training for Relation Extraction），一种面向**半监督文档级关系抽取**的双过程自训练框架：通过联合训练关系分类器与可控文本生成器，生成伪文本与伪标签，并引入对比损失与自适应采样策略，显著缓解长尾关系样本稀缺问题。

## 研究问题与动机
1. **长尾关系挑战**：文档级关系抽取依赖大量标注数据，长尾类别（如 `ethnic group`）因训练样本极少，F1 仅 6.45，而高频类（如 `located in`）可达 83.02。
2. **现有自训练方法局限**：主流方法（如 CAST、CREST）仅通过伪标签增强训练集，无法为长尾关系**注入新信息**，仅能重采样/加权，难以根本改善召回率。
3. **生成质量不可控**：直接使用预训练生成器产生的伪文本可能不包含目标关系三元组，导致噪声累积，影响分类器性能。
4. **半监督学习需求**：现实场景中大量领域内未标注文本可用，需设计更有效的自训练机制以提升模型泛化能力，尤其对低资源类别。

## 核心贡献（创新点）
1. **双过程自训练框架**：首次将自训练同时应用于文档级关系抽取的分类与生成任务，联合优化关系分类器 $\mathcal{C}$ 与可控文本生成器 $\mathcal{G}$，打破仅依赖伪标签的瓶颈。
2. **对比损失提升生成质量**：利用分类器置信度选取正/负样本，通过 ranking calibration loss 拉近正样本生成序列的概率、推远负样本，使生成文本更忠实于输入关系三元组。
3. **自适应伪文本生成策略**：根据各类别在验证集上的精度/召回表现动态调整采样概率与生成温度，对低召回长尾类多采样并注入多样性，对高精密类降低温度保质量。
4. **显著提升长尾关系性能**：在 Re-DocRED 上 DuRE 较最强基线 CAST 提升 **+2.17 F1**，长尾类 F1 提升 **+3.54**；在生物医学 CDG 数据集 5% 标注下即达到可比性能。

## 方法详解
1. **双过程联合训练架构**：共享底层 PLM（如 Flan-T5-base），编码器同时服务于分类与生成。总体损失为加权组合：$\mathcal{L} = \lambda_C \mathcal{L}_C + \lambda_G \mathcal{L}_G$。
2. **关系分类器损失 $\mathcal{L}_C$**：采用 Adaptive Thresholding (AT) 损失，引入阈值类 TH，通过 $\mathcal{L}_P$（正类 logit 高于 TH）与 $\mathcal{L}_N$（负类 logit 低于 TH）联合优化多标签分类。
3. **对比损失 $\mathcal{L}_{CL}$**：对同一关系三元组生成 $m$ 个候选文本，由分类器计算 logit 选取 $x^+$（最高 logit）与 $x^-$（最低 logit），应用 margin loss：$\mathcal{L}_{CL} = \max(0, \beta - \log P_\theta(x^+|y) + \log P_\theta(x^-|y))$。
4. **自适应采样与生成温度**：采样概率 $\phi_r \sim (1-R_r)$，优先多采样低召回类别；生成温度 $\text{temp}_r = \alpha + P_r$，高精密类用高温增加多样性，低精密类用低温保质量。
5. **自训练迭代流程**：每轮用上一轮分类器为未标注数据生成伪标签集 $D_{PL}$，按关系类别分布生成伪文本集 $D_{PT}$，三者合并重新训练分类器与生成器。

## 实验与结果
- **数据集**：通用领域 Re-DocRED（3053 标注/108000 未标注文档）、生物医学领域 CDG（仅 5% 标注数据用作标注集）。
- **评估指标**：Micro-averaged F1，以及 Freq_F1（高频类）、LT_F1（长尾类）、Ign_F1（未见三元组）。
- **主要结果**：
  - **Re-DocRED**：DuRE 取得 **76.84 F1**，超越最佳基线 CAST（74.67 F1）**+2.17**；长尾类 F1 达 **72.88**（CAST 仅 69.34，提升 **+3.54**）。
  - **CDG（5% 标注）**：DuRE 取得 **50.38 F1**，超越 ATLOP-Dual（32.05 F1）约 **+18.33**；在 50% 标注下亦达 **57.08 F1**，超 CAST **+3.05**。
- **消融验证**：移除 SAG（-75.67 F1）、移除 CL（-76.24 F1）、移除伪文本（-74.88 F1）均导致性能下降，证明各模块有效。

## 相关工作脉络
1. **ATLOP（Zhou et al., 2021）**：文档级 RE 基础分类器，采用自适应阈值处理多标签；本文以其作为分类骨干并与生成器联合训练。
2. **CAST（Tan et al., 2023）**：类自适应自训练，依据开发集精度/召回重采样伪标签；本文指出其忽略低精类且无法注入新信息，DuRE 通过生成伪文本补足。
3. **CREST（Wei et al., 2021）**：基于样本频率重采样伪标签缓解确认偏差；DuRE 进一步结合生成多样性与对比优化。
4. **SSR-PU（Wang et al., 2022）**：正无标签学习处理不完全标注；属有监督弱监督范畴，与 DuRE 的半监督自训练路线不同。
5. **DuNST（Feng et al., 2023b）**：先前提出的双噪声自训练用于可控文本生成；本文将其思想拓展至**分类任务**，并首次引入对比校准机制。

## 局限性与未来方向
1. **训练效率低**：伪文本自回归生成耗时，每轮自训练迭代延长整体训练时间（约 39.6 小时）。
2. **偏差风险**：基于开发集性能分布调整采样与生成可能引入人为偏差，需进一步分析。
3. **依赖未标注域内文本**：在极低资源或无未标注文本场景下性能受限。
4. **扩展性待验证**：仅在 Re-DocRED 与 CDG 上验证，未测试于超大语言模型（如 LLaMA-2、GPT-4）或其他 NLP 任务。

## 研究启发与可借鉴点
1. **双过程联合训练范式**：将自训练同时应用于“生成→分类”与“分类→生成”两个方向，可实现优势互补，值得迁移至其他半监督任务（如命名实体识别、信息抽取）。
2. **用分类器信号指导生成质量**：通过分类器置信度构造正/负样本对并施加对比损失，是一种低成本、无需额外标注的生成质量对齐方法。
3. **自适应生成温度调节**：根据类别性能动态调整采样概率与生成温度，平衡多样性与保真度，可用于缓解长尾分布问题。
4. **生成式数据增强优于重采样**：相比简单复制训练样本，可控生成器可产出语义多样、符合三元组约束的新样本，对降低过拟合有实质帮助。

## 关键术语表
- **Document-level Relation Extraction (RE)**：从非结构化文档中提取头实体-关系-尾实体三元组的任务，需跨句建模。
- **Self-Training (ST)**：半监督学习范式，用当前模型为未标注数据生成伪标签并迭代重训练。
- **Adaptive Thresholding (AT) Loss**：引入阈值类（TH）的多标签分类损失，区分正类、负类与阈值。
- **Contrastive Loss (CL)**：通过拉近正样本概率、推远负样本概率，提升生成文本与目标三元组的对齐程度。
- **Self-Adaptive Generation (SAG)**：根据各关系类精度/召回表现动态调整采样概率与生成温度的伪文本生成策略。
- **Long-tail Relations**：训练集中出现频次极低的稀有关系类别，通常召回率低、性能差。
- **Sequence Likelihood Calibration (SLiC)**：用于校准语言模型序列似然的方法，此处借用以优化生成质量。
- **Flan-T5-base**：Google 提出的指令微调编码器-解码器模型，本文用作生成器骨干。

## 可复现要素
- **数据集**：Re-DocRED（公开，含远监督标注与人工标注）、CDG（ChemDisGene，生物医学数据集，公开）。
- **代码/权重**：论文未明确声明开源仓库，但实现基于 Huggingface Transformers v4.31.1。
- **关键超参**：学习率 $5e^{-5}$，AdamW 优化器，warmup ratio 0.06，$\lambda_C=5$、$\lambda_G=1$，$\alpha=0.7$，$\beta=0.3$，top-p sampling $p=0.9$，batch size=8，每个三元组生成 8 个候选文本。
- **硬件环境**：4× NVIDIA Tesla V00，训练时长约 39.6h（Re-DocRED）。
