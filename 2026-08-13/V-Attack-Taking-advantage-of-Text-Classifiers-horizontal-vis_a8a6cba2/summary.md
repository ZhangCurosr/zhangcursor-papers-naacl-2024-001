# 论文速读：V-Attack-Taking-advantage-of-Text-Classifiers-horizontal-vis

## 一句话总结
本文提出了一种名为 **VertAttack** 的新型文本对抗攻击方法，利用当前主流文本分类器只能水平阅读文字的结构性缺陷，将关键词垂直排列以实现对抗扰动；实验表明该方法可在多个数据集上将 Transformer 分类器准确率从 83%–95% 骤降至 1%–36%，同时人类受试者仍能理解 77% 的被扰动文本（原文本为 81%）。

## 研究问题与动机
1. **现有 SOTA 攻击的局限**：当前大多数文本对抗攻击（字符级或词级）均局限于水平空间内的替换/修改，本质上与分类器的阅读域相同，攻击效果存在瓶颈。
2. **分类器的结构性弱点**：基于 Transformer 的现代文本分类器以 token 序列作为输入，按从左到右的顺序处理文本，对垂直书写的文字无法识别。
3. **人类 vs 机器的阅读差异**：人类能够轻松读取水平和垂直排列的文字，而分类器只能处理水平文本；这一差异为"模拟人类绕过分类器"的攻击提供了空间。
4. **攻击的语义保持需求**：理想的对抗攻击应在降低分类准确率的同时保持文本语义可理解性，VertAttack 通过"不替换词、仅改变排列方向"实现这一目标。

## 核心贡献（创新点）
1. **提出 VertAttack 攻击框架**：首次利用分类器无法识别垂直文字这一结构性弱点设计对抗攻击，与现有水平空间攻击形成本质区别。
2. **跨分类器可迁移性验证**：不仅在同一分类器上测试，还系统评估了黑盒场景下反馈分类器与目标分类器不一致时的迁移攻击效果，发现 VertAttack 在跨模型迁移时表现更优（平均降至 47% 准确率，优于 BERT-ATTACK 的 66.5%）。
3. **语义可理解性的人证验证**：通过众包人工标注实验，证明人类仍能以 77% 的准确率理解被垂直扰动的文本（仅比原文低 4 个百分点），确认攻击对人类可读性影响极小。
4. **防御机制探索与对抗增强**：系统研究了简单空白符去除、文本分割、反向还原三种防御策略，并提出通过引入 chaff（概率为 p 的随机干扰字符）进一步增强攻击对 Reverse 防御的抵抗力。
5. **攻击在 offensive language 场景的验证**：在 OLID 数据集的 offensive 子集上验证攻击有效性，同类攻击可使 BERT 分类准确率从 76.7% 降至 1.3%，展示了实际危害。

## 方法详解
VertAttack 分为两个核心步骤：

### 1. Word Selection（词选择）
采用**贪心搜索策略**（Algorithm 1）：
- 遍历输入文本中的每个词，依次将其移除后送入分类器，记录分类概率的变化量（Drop_w = Score_orig − Score_w）。
- 选择使分类概率下降最大的词作为目标修改词（PositionToModify）。
- 该步骤可视为"词重要性"评估，与 Jin et al. (2020) 的 word importance 概念一致。

### 2. Word Transformation（词变换）
采用**垂直排列算法**（Algorithm 2）：
- 对每个选中的词，将其字母垂直堆叠：原词 "happy" 在第 k 行时，取第 k 个字母 'a' 加入输出。
- 非选中词保持水平排列，同时在垂直词的行间插入空白符以维持排版对齐。
- 引入**宽度约束**（width constraint）：每次仅对连续 N 个词执行变换，避免单次处理过长文本。
- 迭代执行：变换后重新查询分类器，若仍未误分类则继续选择下一个最重要词，直至分类器被欺骗。

### 3. 增强策略：Chaff 引入
为对抗分类器的 Reverse 防御，引入概率为 p 的 chaff 机制：
- 在垂直行的空白位置以概率 p 插入随机字母字符（而非纯空白）。
- 限制条件：不与原词相邻的空白处插入，以保持人类可读性。
- 实验显示 p 越大，Reverse 防御效果越差（BERT 准确率从 64.8% 回升至 77.9%）。

### 4. 损失/反馈机制
- **黑盒设定**：攻击者无模型内部参数，仅能通过分类器的标签输出和概率分布获取反馈。
- 攻击目标是最大化分类概率的下降幅度，而非最小化特定损失函数。

## 实验与结果
### 数据集
- **AG News**：4 类新闻分类，平均 38 词
- **SST-2**：电影评论情感分类，平均 20 词
- **CoLA**：语法可接受性判断，平均 8 词
- **QNLI**：问答蕴含任务，平均 28 词（仅扰动假设句）
- **Rotten Tomatoes (RT)**：电影评论情感分类，平均 21 词
- **OLID (OFF subset)**：260 条攻击性语言样本

### 分类器
BERT-base、ALBERT、RoBERTa、DistilBERT（各数据集至少 3 个）

### 核心结果
| 指标 | 数值 |
|------|------|
| SST-2 + RoBERTa | 准确率从 94% 降至 **13%**（下降 81 点） |
| AG News 平均下降 | 约 **83 点** |
| 跨数据集平均最终准确率 | **36.6%**（VertAttack）vs 47.5%（BERT-ATTACK）vs 63.2%（Textbugger） |
| 同分类器反馈平均下降 | 58.7–76.1 点 |
| 跨分类器迁移平均下降 | 35.7–53.8 点 |
| QNLI 最稳健 | 最低准确率仍达 **32%**（相对其他数据集更难攻击） |
| 人类理解准确率 | **77%**（扰动文本）vs 81%（原文本） |

### 防御实验结果
- **Simple/Segment 预处理**：单独使用时可将 Albert 准确率从 14.7% 提升至 29.7%–49.2%，但若攻击者已知预处理策略则防御失效。
- **Reverse 算法**：可强效防御（BERT 准确率从 6.7% 回升至 84.4%），但加入 chaff（p=30%）后降至 39.8%。
- **OCR 场景**：Tesseract OCR 将垂直文本转回文字后，Albert 准确率从 13.6% 提升至 35.7%，但仍低于多数类基线（53.3%）。

### 最强结果
VertAttack 在 BERT 反馈 + BERT 目标的设定下，于 SST-2 和 AG News 上实现最大降幅，SST-2 上 RoBERTa 准确率降至 13%。

## 相关工作脉络
1. **BERT-ATTACK (Li et al., 2020)**：基于 MLM 的词级替换攻击，通过掩码语言模型生成替换词；与 VertAttack 的区别在于 BERT-ATTACK 在水平空间内替换词，VertAttack 不替换词仅改变排列方向，语义保持更好。
2. **Textbugger (Li et al., 2019)**：字符级攻击（插入/删除/交换/替换），攻击强度弱于 VertAttack（最终准确率 63.2% vs 36.6%），且字符级修改易被预处理防御消除。
3. **Hotflip (Ebrahimi et al., 2018)**：白盒字符级翻转攻击，依赖梯度信息；VertAttack 为黑盒攻击，不需要模型内部参数。
4. **SemAttack (Wang et al., 2022)**：通过语义空间搜索自然文本扰动；VertAttack 攻击思路完全不同，聚焦于排版维度而非语义替换。
5. **ValCAT (Deng et al., 2022)**：基于编码器-解码器的变长上下文对抗变换；VertAttack 无需生成模型，仅需黑盒查询即可实施。
6. **Visually attacking NLP (Eger et al., 2019)**：早期视觉对抗研究，使用相似视觉字符（如 a→á）混淆分类器；与 VertAttack 同属视觉维度攻击，但 Eger 的工作针对字符级，VertAttack 针对词级排版。

## 局限性与未来方向
1. **网站格式保留不确定**：VertAttack 依赖保留多余空白和新行符，但许多网站会压缩或删除额外空白，导致攻击效果下降或文本可读性降低。
2. **仅针对 Transformer 分类器**：未验证在 RNN、LSTM 等轻量级模型上的有效性，尽管作者推测非 Transformer 模型同样脆弱。
3. **贪心词选择效率低**：需要逐个词查询分类器，耗时较长；可借鉴 attention 机制或其他高效选择策略（如 Wu et al., 2019）进行优化。
4. **QNLI 数据集攻击难度高**：仅允许扰动假设句（hypothesis）而不扰动前提句（premise），限制了攻击强度；若允许双句扰动，效果可能进一步提升。
5. **Chaff 对可读性的长期影响**：虽然 p=30% 时 83% 文本仍可被人类理解，但更高 p 值可能导致理解率显著下降（Table 11 显示 ≥3 人正确率从 49% 降至 23%）。

## 研究启发与可借鉴点
1. **视角创新启发**：将攻击维度从"词/字符替换"扩展到"排版方向"，证明了利用模型结构性盲点比单纯替换更有效；可迁移至图像分类、语音识别等领域探索类似的结构性弱点。
2. **黑盒反馈机制设计**：采用贪心搜索评估词重要性，计算成本低且易于实现；可与注意力机制结合加速选择过程（如 Wu et al., 2019 的风格迁移方法）。
3. **防御评估的系统性**：不仅评估攻击效果，还系统研究了多种防御策略（预处理、Reverse、OCR），并展示了攻击者如何通过 chaff 对抗防御；这种"攻击-防御迭代"的实验范式值得借鉴。
4. **人类理解性验证的严谨性**：通过众包实验量化人类可读性损失（仅 4 个百分点），为评估攻击实用性提供了可量化标准；建议在后续工作中将此作为标准评估指标。
5. **迁移性作为核心指标**：VertAttack 在跨分类器场景下表现优于对比方法，提示未来攻击方法应将迁移性作为核心评估维度，而非仅关注同模型攻击效果。

## 关键术语表
**VertAttack**：一种新型文本对抗攻击方法，通过将关键词垂直排列来利用分类器无法识别垂直文字的结构性弱点。

**Word Importance / Greedy Selection**：通过依次移除单个词并计算分类概率变化来评估词对分类器的重要性，选择影响最大的词作为攻击目标。

**Blackbox Attack**：攻击者无法获取模型内部参数，仅能通过查询分类器的输出概率和标签来获取反馈的攻击设定。

**Transferability**：攻击在不同分类器之间的迁移能力，即针对一个分类器生成的对抗样本同样能欺骗另一个不同分类器。

**Chaff**：在垂直排列的空白位置以概率 p 插入随机字母字符，用于对抗分类器的 Reverse 防御，增加恢复难度。

**Reverse Algorithm**：一种防御策略，通过识别垂直排列的字符并将其重新组合为水平词来还原原始文本。

**OLID (Offensive Language Identification)**：一个用于检测社交媒体攻击性语言的基准数据集，本文使用其 OFF 标签子集验证攻击在真实场景下的危害。

**SST-2 (Stanford Sentiment Treebank)**：包含电影评论情感标签（正面/负面）的数据集，是本文评估情感分类器攻击效果的核心数据集之一。
